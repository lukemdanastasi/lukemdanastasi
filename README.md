# Hi, I'm Luke D'Anastasi 👋

I run [Streamline Analytics](https://www.streamlineanalytics.ai), a Melbourne data and analytics consultancy. I help businesses actually use their data: getting it out of the systems it's stuck in, modelling it properly, and putting it in front of the people who make decisions, often CFOs and CEOs.

## What I do

- **Data engineering.** I build pipelines, integrations and warehouses on Microsoft Fabric, AWS and SQL, orchestrated with Airflow and scheduled refreshes.
- **Analytics and BI.** I build semantic models and Power BI reporting that finance and operations teams open every day, not once.
- **Local and private AI.** I integrate LLMs and run self-hosted models on my own NVIDIA DGX Sparks, so client data never goes to a third-party AI service.
- **Web platforms.** I build TypeScript and Next.js apps with real data at the core, from client portals to internal tools.
- **Automation.** I set up operational tooling, backups and scheduled jobs so the boring stuff runs itself.
